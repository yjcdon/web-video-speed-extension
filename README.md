# 视频长按加速倍率

适用于 Chrome、Edge 以及其他 Chromium 浏览器。

自定义 B 站和抖音网页版长按右方向键时的临时播放倍率。使用 Manifest V3，无需构建或安装依赖。

## 安装

1. 从 [Releases](https://github.com/yjcdon/web-video-speed-extension/releases/latest) 下载 `web-video-speed-extension-v1.1.1.zip` 并解压，或克隆本仓库。
2. 在地址栏打开 `chrome://extensions`；Edge 请打开 `edge://extensions`。
3. 开启页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `web-video-speed-extension` 文件夹。
5. 刷新已经打开的 B 站或抖音页面。

## 使用

- 点击浏览器工具栏中的扩展图标，即可通过滑块选择倍率。
- 滑块范围为 `0.25×`～`16×`，每一格为 `0.25×`。
- 默认倍率为 `3×`，也可点击 `2×`、`3×`、`4×`、`5×` 快捷按钮。
- 支持 B 站和抖音网页版。
- 短按右方向键完全保留网站自身的行为，扩展不会拦截或模拟短按。
- 只有判定为长按后，扩展才会锁定所选倍率并抵消网站播放器写入的固定倍率。
- 长按右方向键约 0.42 秒后进入自定义倍率，松开后恢复原播放速度。
- 设置通过浏览器同步存储保存，已打开的受支持页面会同步应用新倍率。

## 支持范围

- B 站：视频、番剧播放、列表、收藏列表播放和稍后再看页面。
- 抖音：`www.douyin.com` 和 `douyin.com` 页面中的 HTML 视频。
- 在输入框中或同时按下 Alt、Ctrl、Command、Shift 时，保留原按键行为。
- 页面失去焦点或切换到后台时，会结束临时加速并恢复播放速度。

实际效果受网站播放器行为影响，网站更新后可能需要适配。

## 权限与数据

扩展仅申请 `storage` 权限，用于保存和同步倍率设置；内容脚本仅在清单列出的 B 站和抖音页面运行。源码不包含统计、广告或向外部服务器发送数据的逻辑。倍率设置的跨设备同步由浏览器账号设置决定。

## 项目文件

- `manifest.json`：扩展信息、权限和生效页面。
- `content.js`：长按识别、临时倍率与速度恢复。
- `popup.html`、`popup.css`、`popup.js`：倍率设置面板。
- `icons/`：扩展图标。

## 开发检查

```sh
node --check content.js
node --check popup.js
```

修改扩展后，在扩展管理页点击“重新加载”，再刷新视频页面。
