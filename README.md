# 网页视频长按倍速

为网页视频添加“按住右方向键倍速播放，松开恢复原速”的交互，适用于 Chrome、Edge 及其他 Chromium 浏览器。

自动识别当前可见、正在播放的 HTML 视频，支持 B 站、抖音、YouTube 和其他普通网站，也支持获得键盘焦点的嵌入式播放器。网站无需原本提供长按倍速功能。

长按阈值统一为 **0.5 秒**，倍率可在 **0.25×～16×** 之间调整，默认 **3×**。使用 Manifest V3，无需构建或安装依赖。

[下载 v1.3.1 安装包](https://github.com/yjcdon/web-video-speed-extension/releases/download/v1.3.1/web-video-speed-extension-v1.3.1.zip) · [查看发布说明](https://github.com/yjcdon/web-video-speed-extension/releases/latest)

## 安装

1. 下载上方安装包并解压，或克隆本仓库。
2. 在地址栏打开 `chrome://extensions`；Edge 请打开 `edge://extensions`。
3. 开启页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `web-video-speed-extension` 文件夹。
5. 允许扩展访问需要使用的网站，再刷新视频页面。通用识别需要浏览器授予相应网站的访问权限。

更新已有扩展时，用新版文件替换原扩展目录内容，在扩展管理页点击“重新加载”，再刷新视频页面。

## 使用

播放视频后，按住键盘右方向键 `→` 满 0.5 秒即可应用设定倍率，松开恢复原速。嵌入式播放器请先点击播放器区域，让它获得键盘焦点。

- 点击浏览器工具栏中的扩展图标，即可通过滑块选择倍率。
- 滑块范围为 `0.25×`～`16×`，每一格为 `0.25×`。
- 默认倍率为 `3×`，也可点击 `2×`、`3×`、`4×`、`5×` 快捷按钮。
- 自动识别当前页面内可见的视频，优先选择正在播放的视频；有多个候选时，选择视口内可见面积最大的一个。只有暂停视频时可调整其临时倍率，插件不会自动开始播放。
- B 站和抖音：短按右方向键保留网站自身的行为。
- YouTube 和其他网站：短按右方向键在松开时快进 5 秒；长按期间使用所选倍率，不连续跳秒。为区分短按与长按，快进会在松开时执行。
- 只有判定为长按后，扩展才会锁定所选倍率并抵消网站播放器写入的固定倍率。
- 统一在长按右方向键 0.5 秒后进入自定义倍率，松开后恢复原播放速度。B 站和抖音在此之前仍由网站处理按键。
- 设置通过浏览器同步存储保存，已打开的受支持页面会同步应用新倍率。
- 长按期间直接应用倍率，扩展不显示浮层提示。

## 支持范围

- 支持浏览器允许扩展访问的 HTTP / HTTPS 页面中的 HTML 视频，包括 B 站、抖音、YouTube，以及没有原生长按倍速功能的网站。
- 支持嵌入框架内的 HTML 视频。嵌入播放器需要先点击播放器区域使其获得键盘焦点；选片范围为接收按键的当前页面或框架，不跨框架比较视频。
- 支持在动态加载视频或切换页面后，下次按键时重新识别。
- 在输入框中或同时按下 Alt、Ctrl、Command、Shift 时，保留原按键行为。
- 页面失去焦点或切换到后台时，会结束临时加速并恢复播放速度。

浏览器内部页面、扩展商店等限制扩展运行的页面，以及特殊封装、封闭 Shadow DOM 或未提供可控制 HTML 视频的播放器，需要另行适配或无法支持。实时直播也可能限制变速或快进。实际效果受浏览器和网站播放器行为影响，无法保证所有网站均兼容。

## 权限与数据

扩展申请 `storage` 权限以保存和同步倍率设置，并声明在所有 HTTP / HTTPS 网站及其匹配的嵌入框架中运行内容脚本，用于识别视频并处理按键。浏览器会显示相应的网站访问权限提示，可在扩展管理页调整允许访问的网站。源码不包含统计、广告或向外部服务器发送数据的逻辑。倍率设置的跨设备同步由浏览器账号设置决定。

## 项目文件

- `manifest.json`：扩展信息、权限和生效页面。
- `content.js`：长按识别、临时倍率与速度恢复。
- `popup.html`、`popup.css`、`popup.js`：倍率设置面板。
- `icons/`：扩展图标。

## 开发检查

```sh
node --check content.js
node --check popup.js
node --test content.test.cjs
```
